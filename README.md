# Sobre mim

Olá! Sou **Lucas Rodrigues**, estudante de **Desenvolvimento de Sistemas** no **SENAI Anchieta**, apaixonado por tecnologia e pela construção de soluções que unem desempenho, organização e uma boa experiência para o usuário.

Meu principal objetivo é me tornar um **Desenvolvedor Full Stack**, com especialização em **Java**, **Spring Boot**, **React** e **PHP/Laravel**. Gosto de entender como cada camada de uma aplicação funciona, desde o banco de dados até a interface, buscando sempre escrever código limpo, escalável e de fácil manutenção.

Atualmente também me preparo para ingressar em **Engenharia de Software**, enquanto fortaleço minha base por meio de projetos práticos, estudos contínuos e desafios técnicos.
